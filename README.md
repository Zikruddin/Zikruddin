# Hi, I'm Zikruddin Mujahid

**Software Engineer – Accessibility** at [D2i Technology](https://d2itechnology.com) · IAAP Web Accessibility Specialist (WAS) · Mumbai, India

I've spent about 10 years making websites work for everyone: keyboard users, screen reader users, low-vision users, and people with cognitive disabilities. I audit sites against WCAG 2.2 AA, write the fixes, and build tools that help other teams catch problems earlier.

## What I work on

- **Accessibility audits and remediation**: WCAG 2.0 / 2.1 / 2.2 (A and AA), Section 508, EN 301 549, ADA
- **Screen reader testing**: NVDA, JAWS and VoiceOver on Windows, macOS and iOS
- **Accessible front ends**: semantic HTML, WAI-ARIA patterns for dynamic content, React components that stay usable with a keyboard
- **Accessibility tooling**: Chrome extensions and WordPress plugins
- **Accessible e-learning**: Articulate Storyline 360 courses
